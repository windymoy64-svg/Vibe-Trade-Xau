# ADR-003: Observe-Only Policy Evaluation

## Purpose

Record the authority boundary between the AIOS policy foundation and existing
runtime policy behavior.

## Decision

Policy contexts are immutable and deterministically hashed. The local evaluator
is pure and observe-only. It preserves an existing deny decision, otherwise
returns `NOT_APPLICABLE` when no Phase 3 policy enforcement is configured, and
returns an error observation on evaluation failure. Comparisons explicitly label
the existing/legacy runtime as authoritative. The enforcement adapter cannot
execute actions.

Evidence includes `agent/src/aios/policy/context.py`, `local_evaluator.py`,
`comparison.py`, and `enforcement.py`.

## Alternatives

- Replace legacy decisions immediately.
- Permit by default when no AIOS policy applies.
- Allow the evaluator to invoke runtime actions.

## Tradeoffs

Shadow evaluation permits safe comparison but cannot improve enforcement at
runtime. Preserving legacy denies favors safety over AIOS autonomy.

## Consequences

AIOS policy results are recommendations/evidence only. They cannot widen legacy
permissions or become execution authority through these modules.

## Scope

Phase 3 policy observation. No policy cutover, runtime behavior change, or new
enforcement path.
