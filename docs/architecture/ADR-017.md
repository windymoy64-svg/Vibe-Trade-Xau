# ADR-017: Controlled Evidence-only Shadow Assessment

## Status

Pending architecture review.

## Context

Level 20 compares supplied existing-runtime decisions and AIOS assessments without
placing AIOS on an execution or recommendation path.

## Decision

The closed assessment vocabulary is `approve`, `deny`, `hold`, and `unknown`.
`unknown` means that a determinate assessment is unavailable; it is not equivalent to
deny, hold, or an error. A comparison is:

- **agreement** when both known values are equal;
- **disagreement** when both values are known and differ; or
- **indeterminate** when either value is unknown.

Shadow-session identity binds the existing-runtime identity, adapter, opening time,
and exact snapshot-set digest. Comparison order is canonical sequence order. Each
artifact retains its evidence identifier and digest. Duplicate identities or a
snapshot set different from the bound session fail closed.

## Authority boundary

The existing-runtime decision remains authoritative regardless of classification.
An AIOS assessment is evidence, not an instruction, recommendation, approval, veto,
fallback, or control signal. No comparison result may be consumed to execute, route,
block, retry, or alter runtime activity without a separately approved architecture
decision.

## Public contract versioning and boundaries

Adding, removing, renaming, or reinterpreting a vocabulary value or classification is
a breaking contract change under ADR-015. This decision adds no live shadow mode,
runtime subscription, execution, enforcement, persistence, migration, or cutover.
Level 21 is not authorized by this ADR.
