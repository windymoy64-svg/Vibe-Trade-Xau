# ADR-002: Governance Contracts and Audit Evidence

## Purpose

Record the repository’s data model for governance outcomes and audit evidence.

## Decision

Governance is represented through explicit decision contracts and audit events,
with sink abstractions and JSONL/composite implementations under
`agent/src/governance/`. Decisions carry explicit outcomes and evidence can be
reported without granting execution authority. Foundation import tests prevent
governance code from depending on agent, swarm, live, tools, providers, trading,
frontend, API, deployment, or experiment packages.

## Alternatives

- Boolean decisions without rationale or identity.
- Logging-only governance with no typed event contract.
- Governance code directly invoking operational subsystems.

## Tradeoffs

Typed decisions and durable evidence add schema and sink management. Separation
from runtime packages prevents direct enforcement through this layer.

## Consequences

Governance output can be inspected, compared, and certified as evidence. A
separate authorized adapter would be required for enforcement.

## Scope

Phase 2 governance contracts, audit, and reporting foundation only.
