# ADR-005: Research-Only Runtime Observation Model

## Purpose

Record the limits of the runtime foundation represented under `src/aios/runtime`.

## Decision

Runtime context is immutable and restricted to the `RESEARCH` environment.
Isolation profiles are declarations only and must remain unenforced. The runtime
supervisor creates observations with `executable=false` and
`authoritative=false`; it has no execution authority.

Evidence includes `agent/src/aios/runtime/context.py`, `isolation.py`, and
`supervisor.py`.

## Alternatives

- A supervisor that provisions or terminates workloads.
- Enforced isolation in the foundation phase.
- Reusing the same model for live execution.

## Tradeoffs

The model can be validated safely alongside the existing runtime, but declared
isolation must not be mistaken for an enforced security boundary.

## Consequences

No caller may treat these classes as proof of sandboxing or as permission to
execute. Existing runtime mechanisms remain responsible for behavior.

## Scope

Phase 5 research observation contracts only; no provisioning or live runtime.
